## О проекте

**FontSpace** — веб-приложение для поиска, предпросмотра и сохранения шрифтов в личную коллекцию. Пользователь может подобрать гарнитуру по стилю и связать любимые шрифты со своими дизайн-проектами.

Цель лабораторной работы — настроить совместную работу четырёх независимых Docker-контейнеров и организовать хранение данных в PostgreSQL.

## Возможности

- **Каталог шрифтов:** поиск по названию, фильтрация по категориям.
- **Предпросмотр:** можно ввести собственный текст для сравнения гарнитур.
- **Избранное:** добавление шрифтов в коллекцию и удаление из неё.
- **Проекты и заметки:** редактирование названия проекта и комментария к сохранённому шрифту.
- **Сохранение данных:** коллекция хранится в PostgreSQL, а не только в браузере.

## Архитектура

Приложение состоит из четырёх сервисов:

| Контейнер | Стек | Назначение |
|---|---|---|
| **frontend** | HTML, CSS, JavaScript, Nginx | Веб-интерфейс и взаимодействие с пользователем |
| **backend** | Python, FastAPI | REST API и запросы к базе данных и каталогу |
| **db** | PostgreSQL 16 | Сохранение избранных шрифтов, проектов и заметок |
| **web-service** | Python, FastAPI | Поиск гарнитур: Google Fonts API либо локальный эмулятор |

```text
Браузер
   │
   ▼
Frontend (Nginx :8081)
   │ /api/*
   ▼
Backend (FastAPI)
   ├──► PostgreSQL (избранное)
   └──► Web-service (каталог шрифтов)
               └──► Google Fonts API (если указан ключ)
```

**Важно:** без ключа Google Fonts API проект использует встроенный каталог шрифтов (локальный эмулятор). Он позволяет показать работу отдельного Web-сервиса без регистрации на внешнем API. Для реального API можно задать `GOOGLE_FONTS_API_KEY` в файле `.env`.

## Как запустить на компьютере

**Требуется:** установленный и запущенный Docker Desktop.

1. На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте терминал в папке с `docker-compose.yml`.
3. Выполните команду:

```bash
docker compose up --build -d
```

4. Откройте **http://localhost:8081**.

Проверить состояние четырёх контейнеров:

```bash
docker compose ps
```

Остановить приложение (данные сохранятся):

```bash
docker compose down
```

> Примечание: `localhost` доступен только на компьютере, где запущено приложение; это не публичный хостинг.

## Демонстрация для преподавателя

1. Откройте каталог и выполните поиск, например `Montserrat`.
2. Измените категорию и введите собственный текст предпросмотра.
3. Нажмите **«Сохранить»** у понравившегося шрифта.
4. Перейдите во вкладку **«Избранное»** — сохранённый шрифт появится в списке.
5. Нажмите **«Изменить»**, укажите название проекта и заметку, сохраните.
6. Удалите тестовый шрифт из избранного.
7. Покажите в Docker Desktop четыре работающих контейнера. Для проверки сохранения можно перезапустить контейнеры без удаления volume.

При первом создании базы добавляются два демонстрационных шрифта.

## REST API

| Метод | URL | Действие |
|---|---|---|
| GET | `/api/fonts` | Поиск и фильтрация каталога |
| GET | `/api/favorites` | Получить избранные шрифты |
| POST | `/api/favorites` | Добавить шрифт |
| PATCH | `/api/favorites/{id}` | Изменить проект или заметку |
| DELETE | `/api/favorites/{id}` | Удалить шрифт |
| GET | `/api/health` | Проверить доступность Backend |

В Docker Compose предусмотрены `healthcheck`, `depends_on`, переменные окружения и постоянный том `fontspace_db`, сохраняющий PostgreSQL при перезапуске.
