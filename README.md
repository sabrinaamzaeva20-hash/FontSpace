# FontSpace — библиотека шрифтов

**Амзаева Сабрина, группа 223-322**  
Дисциплина: Проектирование веб-сервисов  
Вариант №50 — Библиотека шрифтов.

Проект содержит четыре сервиса Docker Compose: Frontend, Backend, PostgreSQL и Web-service (каталог Google Fonts с локальным режимом).

Запуск: `docker compose up --build -d`, затем открыть http://localhost:8080.

Функции: поиск и фильтрация шрифтов, предварительный просмотр и управление избранным.
